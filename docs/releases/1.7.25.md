# 1.7.25

两条线：**装得上了**（一键脚本，把加载源对齐这一步固定进流程）和**记得住了**（ACP 客户端接入的契约）。
宿主补丁不变：仍是 1.7.24 的 **74** 条，补丁 ID 与锚点定义未改，已应用过的机器不需要重新「应用」。

## 一键脚本：装上 = 生效

```sh
curl -fsSL "https://raw.githubusercontent.com/atompilot/dsh-purge/master/scripts/quickstart.sh" | sh
```

五步固定顺序，缺一步都不算装好：装插件（Release SHA256 + 快照 + 旧包迁移）→ `app.asar` 解包并让位（原归档备份到 `~/Library/Application Support/dsh-purge/asar-backup/`）→ 打 74 条宿主补丁 → `codesign --force --deep --sign -` 重签 → 逐条校验并打印回滚命令。

- 为什么要这一步：Electron 优先加载 `Resources/app.asar`，补丁却写在 `Resources/app/`；不让位就是"界面全绿、补丁全空转"。
- 参数：`--dry-run` / `--status` / `--revert` / `--version=X.Y.Z` / `--profile=NAME` / `--recover-legacy` / `--no-sign`。
- 边界：宿主在跑就停；不改 npm 源、不关 TLS/SHA256、不自动重启；解包校验、补丁、语法检查、重签任一失败即非零退出。
- 代价如实写：重签后 DSH 自动更新失效（以后手动装更新包再重跑脚本），TCC 权限可能要重授权一次。
- 从 ≤1.7.23 升级：旧版权限补丁会留下"备份本身不干净"的现场，加 `--recover-legacy` 用同版本官方归档把那份备份换回原文再继续；其它原因不猜。

## ACP 客户端接入

第三种运行形态被正式记录：**ACP 客户端（T3 Code 等）通过 `dsh --profile acp` 拉起宿主**。

这一形态最容易踩的坑是"半套生效"——宿主补丁是全局的（同一个 `Resources/app` 树），但提示词注入是 **profile 级插件**。空 `acp` profile 里宿主补丁生效但人设没换、`probe` 不回显，而界面上一切正常、没有任何报错。本版把这条链路、验收方法和后续维护点写进文档，并用测试钉住，避免下一个人按桌面版经验去接 ACP。

本版**不含宿主补丁变更**：仍然是 1.7.24 的 74 条补丁。

## 升级注意

- 桌面版 / web profile：本版**不含补丁变更**，不需要重新「应用」，也不需要重启 DSH。
- 想要"一条命令装到位"，用上面的 quickstart；只想体检用 `--status`，回滚用 `--revert`。
- ACP profile 是新装插件，命令固定为：
  ```sh
  dsh plugin --profile acp add \
    https://github.com/atompilot/dsh-purge/releases/download/v1.7.25/dsh-purge-community-1.7.25.tgz
  ```
  装完确认 `dsh.profile.bundles` 含 `dsh-purge-community`，再把 `dsh-purge-redteam-ui` 在该 profile 的 `cordis.patch.yml` 里 `disabled: true`。
- DSH 桌面更新后 `app.asar` 会回归，launcher 优先 asar → ACP 侧会**静默**变回未打补丁。顺序固定为 `quickstart.sh`（或 `purge-align`）→ 重开 ACP 客户端会话。

## 已知限制

- 其它 ACP 客户端（Zed 等）未实测；Windows 上的 ACP 接入未实测。
- ACP 下 ACP 交互式审批 / 等待回答语义未验证；面板与演练台 HTTP 桥不适用（无 `webServer`），不做兼容承诺。
- `selfcheck` 只覆盖宿主与当前 profile，不覆盖 `acp` profile；ACP 侧验收必须用"启动自检 + probe 回显"两条独立证据。
- quickstart 只覆盖 macOS 桌面版；Windows 仍走 `scripts/install.ps1`，asar 换包由宿主自己的交接助手完成。
- 重签必然带来"自动更新失效 + TCC 可能重授权"；这两条是 ad-hoc 签名的事实，不承诺规避。
